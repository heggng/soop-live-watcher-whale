# SOOP 방송 시작 알리미 — 네이버 웨일용

이 버전은 Tampermonkey 사용자 스크립트가 아니라 Chromium Manifest V3 확장 프로그램입니다.
SOOP 페이지가 없어도 네이버 웨일이 실행 중이면 백그라운드 알람이 방송 상태를 확인합니다.

현재 버전: **2.3.4**

## 다운로드 및 설치

**[최신 버전 ZIP 다운로드](https://github.com/heggng/soop-live-watcher-whale/releases/latest/download/soop-live-watcher-whale.zip)**

1. 위 링크를 눌러 ZIP 파일을 다운로드하고 원하는 폴더에 압축 해제합니다.
2. 네이버 웨일 주소창에서 `whale://extensions`를 엽니다.
3. 확장앱 관리 화면의 **개발자 모드**를 켭니다.
4. **압축해제된 확장앱을 로드합니다**를 누릅니다.
5. 압축을 푼 폴더 중 `manifest.json`이 바로 들어 있는 폴더를 선택합니다.
6. 웨일 툴바에서 확장 프로그램 아이콘을 고정하고 클릭하면 크기 조절 가능한 전용 설정 창이 열립니다.

> Chromium 보안 정책상 GitHub에서 배포하는 확장 프로그램은 웹스토어 확장처럼
> 한 번의 클릭만으로 자동 설치할 수 없습니다. 다운로드 후 최초 한 번은 위의
> `압축해제된 확장앱을 로드합니다` 과정이 필요합니다.

## 업데이트

1. 최신 ZIP을 다시 다운로드해 압축을 풉니다.
2. 현재 설치에 사용한 폴더에 새 파일을 덮어씁니다.
3. `whale://extensions`에서 이 확장 프로그램의 새로고침 버튼을 누릅니다.

같은 폴더를 유지하면 저장한 스트리머 설정도 그대로 유지됩니다.

## 사용

1. 스트리머 ID와 선택적인 표시 이름을 입력해 **추가**합니다.
   표시 이름을 비워 두면 입력한 ID로 SOOP 닉네임을 조회해 자동으로 채웁니다. 조회에 실패하면 ID가 표시 이름으로 사용됩니다.
2. 각 스트리머의 **감시** 및 **자동 열기**를 선택합니다.
3. 5~60초 확인 주기, 데스크톱 팝업, 알림음을 설정합니다. 기본값과 권장값은 10초입니다.
4. **설정 저장**을 누릅니다.
5. **알림 테스트**와 **지금 확인**으로 동작을 확인합니다.

독고혜지_의 스트리머 ID 예시는 `dokkhye0000`입니다.

## 동작 특성

- 웨일이 실행 중이면 SOOP 탭이나 다른 웹페이지가 없어도 작동합니다.
- 방송 시작 시 방송번호를 저장해 같은 방송은 한 번만 알립니다.
- 자동 열기는 `https://play.sooplive.com/{스트리머ID}`를 별도 웨일 창으로 엽니다.
- 감시 목록은 스트리머 프로필 이미지와 함께 카드 형태로 표시되며, 이미지를 불러오지 못하면 이니셜 아바타로 대체합니다.
- 웨일이 완전히 종료되어 있으면 감시하지 않습니다. 다시 실행하면 즉시 한 번 확인하고 주기 감시를 재개합니다.
- 브라우저나 운영체제에서 웨일 알림이 차단되어 있으면 데스크톱 알림이 표시되지 않을 수 있습니다.
- 빠른 감시는 숨은 Web Worker가 5~60초 간격으로 실행하며, 1분 단위 브라우저 알람이 보조합니다.
- 5초 주기는 스트리머 1명당 시간당 최대 720회, 10초 주기는 최대 360회 상태를 확인합니다. 등록 인원이 많다면 10초 이상을 권장합니다.
- 알림 아이콘은 웨일 알림 API와 호환되는 내장 PNG를 사용하며, 이미지 로드 실패 시 더 작은 PNG로 한 번 재시도합니다.
- 설정은 툴바의 작은 팝업이 아닌 760×840 크기의 전용 창으로 열리며 크기를 조절할 수 있습니다. 감시 목록과 창에 스크롤이 중복되지 않고, 하단 실행 버튼은 항상 표시됩니다.

## 개인정보 및 권한

- 설정과 방송 알림 기록은 브라우저의 로컬 확장 프로그램 저장소에만 저장됩니다.
- 방송 상태 확인과 닉네임 조회를 위해 `https://live.sooplive.com/*`, `https://st.sooplive.com/*`에 접근하며, 프로필 이미지 표시를 위해 SOOP 이미지 호스트를 사용합니다.
- 원격 JavaScript나 외부 분석 도구를 사용하지 않습니다.
- 이 프로젝트는 SOOP Corp.의 공식 제품이 아닌 비공식 사용자 프로젝트입니다.
